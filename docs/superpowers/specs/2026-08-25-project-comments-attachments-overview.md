# 设计规格说明书 (Spec) - 项目全量留言备注与附件筛选看板

## 1. 问题背景
目前项目中，用户可以为每个 WBS 节点（模块）或叶子任务单独添加留言备注、完成进展和附件证据。这些内容分散在各个节点和任务的“评论抽屉”中，缺乏一个全局视角。
当项目进入中后期或结项阶段，管理者、执行者或审计人员希望能够在一个统一的入口：
1. **查看整个项目的所有留言备注**：随时追溯项目的业务讨论、风险记录及完成结论。
2. **高效筛选和追溯项目附件**：按类型（图片、PDF、Markdown）筛选所有阶段性交付的证据链。
3. **定位关联项**：点击可以直接看到这条留言备注或附件对应 WBS 分解结构中的哪个节点或任务，具备回溯上下文的能力。

## 2. 方案概要
本项目采用 Next.js + React + Tailwind + Local JSON 模拟数据库。我们将：
- **后端服务扩展**：在 `comment-service.ts` 中增加 `getProjectComments(projectId)` 接口，支持递归查找属于该项目所有子节点、任务的留言备注，并按时间倒序返回。
- **API 路由升级**：更新 `/api/comments` GET 路由，支持传入 `projectId` 参数，以便前端一次性获取该项目的所有留言备注树。
- **全新前端看板 (ProjectCommentsDrawer)**：
  - 设计一个侧边栏或大弹窗，以时间线 / 流式布局展示所有留言。
  - 内置筛选栏：
    - **内容搜索**：模糊匹配评论内容、作者。
    - **附件类型筛选**：全部 / 仅看含附件的留言，并支持按“图片 (Image)”、“文档 (PDF)”、“Markdown (.md)”等类型精细过滤。
    - **节点关联筛选**：下拉选择特定的模块/节点，只查看该模块下的备注。
  - 备注展示卡片：
    - 明确标识其属于哪一个节点或任务（带有“节点：xxx”或“任务：xxx”标签）。
    - 渲染附件预览、下载按钮。
    - 保留回复嵌套结构，方便查看对话脉络。
- **醒目的全局入口**：
  - 在项目详情页的头部 (`ProjectHeader`) 增加一个常驻按钮，命名为 **“项目备注与附件看板”**，并显示当前项目总备注数，点击一键唤起。

## 3. 技术选型
- **数据流**：React State 管理过滤状态，使用已有的 `safeFetchJson` 异步获取数据。
- **UI & 动效**：基于 Tailwind CSS，配合 `lucide-react` 图标库和 `motion` (来自 `motion/react`) 进行平滑的展开、折叠及过滤动画。
- **附件预览**：复用项目现有的 `AttachmentPreviewModal` 统一预览组件，确保用户体验一致。

## 4. 范围边界
- **只读与定位为主**：此全量看板专注于“查阅”和“过滤筛选”。若需发表新评论或针对特定节点追溯，看板内提供“发表备注”入口（默认关联项目根节点，或提供链接跳转至对应节点的抽屉）。
- **附件不占用额外存储**：附件统一走现有的七牛云上传代理，该看板只对数据字段进行筛选和解析，不增加新的上传和存储负担。
